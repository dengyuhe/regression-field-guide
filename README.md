# Regression Field Guide

A step-by-step reference for a complete regression analysis in Python, with copyable code for each stage:

1. Data inspection
2. OLS and residual plots
3. Cross-validation
4. Feature engineering
5. Functional form selection (Ridge, Lasso, Huber, tree models)
6. Predicting on a test set and delivering a CSV
7. Common pitfalls and extras

**Read it online:** https://dengyuhe.github.io/regression-field-guide/

Built with pandas, statsmodels and scikit-learn. The page is a single self-contained `index.html`.

Corrections and suggestions are welcome as issues.
